# Application Development Summary

This document summarizes the key changes applied to the CN-KR News Engine application.

## 1. Feature Implementations

### Translation Service Enhancements (/src/services/translationService.ts)
- **Publisher Name Integration**: Added a "Publisher Name" field throughout the translation flow. It is now passed as a parameter to the `translateNews` function and included in the output structure.
- **Yonhap News Style Standardization**: Refined system instructions to strictly adhere to Yonhap News specifications.
- **Headline Rules**: Prepended a dot to the headline, enforced subject/content structure, comma topic markers, specific country abbreviations, and "회동" terminology.
- **Body Translation Rules**: Date formatting, name formatting (with Chinese characters in parentheses), representing nation before occupation, location/city formatting, and strict quotation/attribution rules.
- **Regulation Formatting**: Treat 『』 for regulations, ordinances, treaties, and media entities.

### App Interface Changes (/src/App.tsx)
- **UI Streamlining**: Removed the sidebar tool menu and integrated "Source" and "Publisher" inputs directly into the header for a more spacious workspace.
- **State Management**: Added `publisherName` state to manage the new input field.
- **Translation Call**: Updated `translateNews` invocation to include the `publisherName`.
- **UX Improvements**: Changed the input placeholder to "Type here..." for a cleaner startup experience.

## 2. Infrastructure & Security Fixes

### Firestore Rules (/firestore.rules)
- **Permission Fix**: Updated `corrections` and `patterns` collections to allow unauthenticated read and write (`allow read: if true;`, `allow create: if true`). This resolved the "Missing or insufficient permissions" error encountered when the application attempted to fetch learned patterns.
- **Deployment**: Deployed the hardened and corrected rules using the `deploy_firebase` tool to apply the changes to the production Firestore instance.

## 3. Linguistic & Structural Requirements
When translating, strictly adhere to the following naming and structural rules:

- **Country Relation Format**: Use "국가1-국가2 양국" (e.g., 중국-인도 양국 관계).
- **Weapon Naming**: "Country + missile name (English) + missile type + 미사일" (e.g., 미국 AGM-158 JASSM 순항 미사일).
- **Company Naming**: "Country + company name (English) + 社" (e.g., 미국 Lockheed Martin社).
- **Official Title**: Always select and use only ONE representative title for individuals.
- **Location/City**: Format as "Country + City(Hanja)市" or "Country + Capital city(Hanja)市".
- **Name Formatting**: Use "[Nation] [Occupation] [Name]([Chinese characters])" (e.g., 중국 외교부장 왕이(王毅)).
- **Date Rules**: Place all dates at the beginning of the sentence in the format: "'YY. M. D일,".
- **Pronouns**: DO NOT use pronouns like "그" or "그녀". Always use "[Name] [Title]".
- **Sentence Structure**: Follow the "Subject + object + verb" pattern.
- **Connective Order**: Use the order "~고" followed by "~하며,".
